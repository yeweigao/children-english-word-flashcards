# 儿童英语单词闪卡（children-english-word-flashcards）

拍一张作业页，找出孩子值得记住的词，做成卡，按记忆规律复习。

产品目的：**从输入材料里找出孩子值得记住的单词**——不是错题归因本、不是改错报告。错因诊断只是后台的选词手段，前台交付物始终是词本身：词 + 材料原句 + 一句人话理由。

## 核心流程

1. **拍照找词**——家长拍 1–6 页作业/试卷，服务端逐页读（3 页并发）、跨页按学习单位去重。LLM 视觉直接读图，**不用 OCR**；识别是服务端任务，关掉页面也能继续跑，回来认领结果。
2. **后台诊断，前台只给词**——模型先结合试卷内容与孩子作答做错因诊断，再判断哪些词值得记：只有词义/拼写/搭配/短语概念等词汇层面的根因才成卡，审题、信息提取、推理、粗心类错误不成卡。**错题 ≠ 写错单词**（选错键位图、把姓答成全名、答语选错，都不是拼写错）。
3. **学习单位不总是单个词**——可以是短语，也可以是对比对（如 last name vs full name）；同一词在卷子别处答对要降级（相遇检验）；阅读题失分往下追一层，只挑承重的超纲词（超纲＋该题判断压在这个词上），试卷自带的中文注释词是出卷人标出的超纲强信号。
4. **没拍到作答就不给改错**——先判照片成分（只有卷面／有作答／有批改），只有卷面时改错线关闭，只能从材料本身挑值得学的词，并明示「还没看到作答」。
5. **候选分两层**——孩子当前水平（Movers）的词也收（在真实材料里承重、属课内核心、有现成出生句的）。推荐词直接生成闪卡返回，中间零个需要家长阅读决策的页面；「更多可选」池退到结果页下方，一键补卡。
6. **学习与复习**——正面读出生句选词义；背面两拍（先词+义，例句后一拍才原地出现）；热身在选词填空与拼一拼之间轮换，打字挖空收尾。掌握 = 在四个场景里都能产出（认卡、挖空、听写、造句），四格全亮才毕业。

## 调度：FSRS 是唯一核心

- 不许另建 FSRS 之外的调度逻辑。排期只由 FSRS 决定；复习行为形成评级喂回 FSRS。
- **被动评级**：自评按钮已删除。评级由行为推导——首答定级：错/重试后对 = Again，提示或明显慢于本人常速 = Hard，干净一次对 = Good，**永不发 Easy**；首键延迟只在 Good↔Hard 之间移动；个人基线满 20 条同类记录才启用延迟分档；原始行为数据逐条存入复习记录，可重算。
- 激励层只从复习记录派生，**永远不写调度**：任务按孩子自己基线定、要可赢；连胜考核出席（到期清零时才续），最多 2 天免费自动暂停日，无愧疚文案；**无货币、无装扮商店、无红心/体力、无联赛、无愧疚推送**。进步可视化（毕业词增长、家长周报、回顾卡）是核心。

## 发音：产品自带服务端语音

- 不用设备语音：iPhone 网页拿不到 iOS 设置里下载的 Enhanced/Premium 语音，Siri 语音全屏蔽。发音走产品自带服务端高质量语音（英式/美式两档），生成一次后缓存复用。
- **自动朗读**（默认开）：只读展示面——正面入场读出生句、背面第一拍读词、例句出现与滑动时读当前句；**生产面永不自动读出目标英文**（拼一拼、选词填空的空本身就是答案）。家长可在档案里关闭。
- 跟读功能已去掉：录音 + 语音识别的不确定性太多。

## 界面哲学：少即是多

- **非必要不显示**：元素不是摆出来等看，而是预判用户这一步会做什么动作、到那一步才出现下一步。找词页主角只有一个大的摄像头主按钮。
- 学习界面只有三个共用系统，各一份实现：**(1) 卡片**——唯一卡面规格，只装内容、不放操作按钮、不裁切；**(2) 底部操作区**——所有流程按钮只在这里，位置跨屏恒定；**(3) 情绪弹窗**——夸奖、安慰、连击、鼓励语音只走弹层这一独立 UI 系统，绝不插入现有界面流。
- **庆祝不许串屏**：庆祝的显示与语音只属于产生它的那一拍、在那一屏内结束，翻页后必须清零，错过就整体丢弃、绝不延迟补发到下一屏。

## 技术架构

- 前端：React 19 + TypeScript（`client/src/App.tsx`，单文件应用），Tailwind CSS。
- 服务端：server actions（`server/src/actions.ts`），Drizzle ORM + SQLite（`server/src/schema.ts`，迁移在 `drizzle/`）。
- 视觉识别与语音走运行时能力：照片由运行时提供的视觉模型直接读图；发音由宿主自带的神经语音 CLI 合成（`server/src/privileged.ts`），语音按口音+文本缓存。**仓库里没有任何 API 密钥。**

### 运行环境

这是一个 **Muse space**（TypeScript runtime，见 `space.json`）：`@hatch/space-sdk` 由运行时提供，server actions、blob 存储与视觉/TTS 能力都依赖该运行时。**不接 Muse 运行时，这份源码不能直接跑起来**——仓库发布源码供阅读、复用与版本管理，不是开箱即用的独立部署。

## 隐私

- 照片**临时暂存服务端，识别一完成立刻删除**（失败/30 分钟超时也要清），不长期保存、不作他用。
- 数据库（`app.db`）、blob 存储（语音缓存、照片暂存）与构建产物**不在仓库里**；仓库不含任何孩子的卡片、复习记录与照片。

## 目录结构

```
client/                 React 前端（App.tsx 为主应用）
server/src/actions.ts   全部 server actions：找词任务、卡片、复习、激励派生
server/src/schema.ts    Drizzle schema：settings / cards / reviews / findJobs / activity
server/src/privileged.ts 宿主 TTS 合成（特权 handler）
drizzle/                SQL 迁移（0001–0006）
space.json              Muse space 清单（runtime / slug）
```
